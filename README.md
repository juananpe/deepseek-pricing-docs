# DeepSeek Pricing — Static Archive

Archivo estático **no oficial** de una única página de la documentación pública de DeepSeek:

- **Página original:** <https://api-docs.deepseek.com/quick_start/pricing/>
- **Fecha de la copia:** 29 de octubre de 2026
- **Contenido:** una sola página (`index.html`) y sus recursos visuales (CSS, favicon, logos e iconos).

## Aviso

Este repositorio **no está afiliado, patrocinado ni respaldado por DeepSeek**. Se publica con fines **educativos** y de archivo/consulta offline.

Todos los textos, marcas, logotipos y hojas de estilo son propiedad de sus respectivos titulares (DeepSeek). Si eres titular de derechos y quieres que este archivo se retire, abre un issue en este repositorio y se eliminará.

La página incluye `noindex` y un aviso visible de "archivo no oficial" para evitar confusión con el sitio oficial.

## Publicación

Servido con GitHub Pages desde la rama `main` (raíz del repositorio). No requiere build: es HTML/CSS estático.

Localmente también funciona sin servidor, abriendo `index.html` en el navegador.
